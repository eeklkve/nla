# nla

Реализации алгоритмов численной линейной алгебры

## Структура

- `src/nla/` — реализации алгоритмов
- `tests/` — тесты
- `notebooks/` — эксперименты по лекциям
- `labs/` — практические ДЗ курса
- `theory/` — теоретические ДЗ
- `docs/` — отчёты по блокам, графики в `docs/figures/`

## Запуск

    uv sync
    uv run pytest
